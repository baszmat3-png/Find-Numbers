# دليل الأسماء والأرقام

منصة بسيطة لحفظ الأسماء والمناصب وأرقام الهواتف. يستطيع أي شخص البحث بالاسم أو المنصب أو الرقم، وإضافة جهة اتصال جديدة.

**التقنيات:** Node.js + Express + PostgreSQL (على Render) — بدون أي أدوات بناء.

## التشغيل محليًا
```bash
npm install
npm start
```
افتح http://localhost:3000 (يُحفظ محليًا في `data/contacts.json` عند عدم وجود قاعدة بيانات).

## الرفع على GitHub
```bash
git init
git add .
git commit -m "first commit"
git branch -M main
git remote add origin https://github.com/USERNAME/contacts-directory.git
git push -u origin main
```

## النشر على Render (الطريقة الأسهل)
1. ادخل إلى https://dashboard.render.com ثم **New +** ← **Blueprint**.
2. اربط حساب GitHub واختر المستودع.
3. سيقرأ Render ملف `render.yaml` وينشئ الخدمة وقاعدة PostgreSQL تلقائيًا. اضغط **Apply**.
4. بعد اكتمال النشر افتح رابط `onrender.com` الظاهر.

> ملاحظات الخطة المجانية: الخدمة تنام بعد فترة خمول (أول فتح يتأخر قليلًا)، وقاعدة PostgreSQL المجانية تنتهي بعد 30 يومًا ما لم تُرقَّ إلى خطة مدفوعة، فخذ نسخة احتياطية أو رقِّها للاستخدام الدائم.

## الاستيراد والتزامن الفوري
- زر **📥 استيراد** في الصفحة العامة (وفي لوحة التحكم) يقبل ملفات **Excel** (xlsx/xls) و**CSV** و**VCF**.
- يتعرف تلقائيًا على أعمدة الاسم والرقم والمنصب (إن وُجد) سواء كانت العناوين عربية أو إنجليزية أو بدون عناوين، ويعرض معاينة قبل الإضافة.
- الأرقام المكررة تُتجاهل، والأرقام بلا رمز دولي تأخذ رمز البلد المختار (الافتراضي +964).
- الحدود: 1000 جهة في المرة و5 عمليات استيراد في الساعة للزوار، و10000 جهة للمسؤول.
- أي إضافة أو استيراد أو تعديل أو إخفاء يظهر عند الجميع فورًا بدون تحديث الصفحة (Server-Sent Events).

## عدّاد الأسماء
يظهر أعلى الصفحة العامة إجمالي الأسماء المضافة (الظاهرة فقط، دون المخفية) ويتحدث فورًا مع كل إضافة أو استيراد أو حذف أو إخفاء.

## الأرقام وأزرار التواصل
- عند الإضافة يختار المستخدم رمز البلد (الافتراضي 🇮🇶 +964) ثم يكتب الرقم المحلي، فيُحفظ بالصيغة الدولية مثل `+9647501234567`.
- كل نتيجة بحث تعرض زرين: **💬 واتساب** (يفتح محادثة عبر wa.me) و**📞 اتصال**.
- الأرقام القديمة المحفوظة بدون رمز تُعامَل كأرقام عراقية.

## لوحة التحكم (مخفية)
لا يوجد أي رابط للوحة في الصفحة العامة، ومسار `/admin` يعطي 404. تُفتح فقط عبر **مسار سري تختاره أنت**:

1. عند النشر على Render سيطلب منك قيمة `ADMIN_PATH` — اكتب كلمة طويلة يصعب تخمينها، مثل `panel-x7k29qd` (8–64 حرفًا: حروف إنجليزية وأرقام و - _).
2. رابط اللوحة: `https://YOUR-APP.onrender.com/panel-x7k29qd`
3. أدخل مفتاح المسؤول `ADMIN_KEY` (من Render ← Environment، ويمكنك تغييره).

**إخفاء/إظهار:** زر 🙈 إخفاء بجانب كل اسم (أو «إخفاء المحدد» جماعيًا) يخفي جهة الاتصال عن كل الزوار وعن البحث العام، وتبقى ظاهرة لك فقط في اللوحة بعلامة «مخفي». زر 👁 إظهار يعيدها للجميع.

الحماية على طبقتين: المسار السري، ثم المفتاح. ولو لم تضبط `ADMIN_PATH` تبقى اللوحة معطّلة بالكامل.
للتجربة محليًا: `ADMIN_PATH=panel-test1234 ADMIN_KEY=secret npm start`

## الواجهة البرمجية
- `GET /api/contacts` — قائمة جهات الاتصال
- `POST /api/contacts` — `{ "name": "", "role": "", "phone": "" }` (حد 20 إضافة/ساعة لكل IP)
- `POST|PUT|DELETE /api/admin/contacts[/:id]` — للمسؤول فقط (ترويسة `x-admin-key`)
